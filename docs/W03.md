Web 是 World Wide Web（WWW，全球資訊網） 的簡稱
Web 與 Internet 的差別：
Internet（網際網路）：指底層連通全球的實體基礎設施（海底光纖、伺服器、路由器）。
Web（全球資訊網）：指運行在 Internet 之上的應用與內容服務（HTML 網頁、網站、HTTP 協定）。

伺服器（Server） 在資訊領域主要指提供服務、資料或資源給其他電腦（用戶端/Client）的系統。它可以指實體硬體，也可以指運行中的軟體程式。

Uvicorn 是一個極速的 ASGI 伺服器（基於 uvloop 與 httptools）。它的工作是接收來自網路的 HTTP / WebSocket 請求，將其解析後傳遞給 ASGI 應用程式處理，最後再將結果回傳給用戶。
選擇 Uvicorn 的核心原因在於它提供了 極致的執行效能、原生的非同步（Async）支援，以及與現代 Python Web 框架（如 FastAPI、Starlette）的 無縫整合。
1. 極速效能（Python 界最快的 Web 伺服器之一）
2. 完美的 ASGI 標準實作
3. 開發體驗極佳（Developer Experience）
4. 生產環境（Production）彈性高

ASGI（Asynchronous Server Gateway Interface，非同步伺服器閘道介面）是 Python 規範中，介於 Web 伺服器（如 Uvicorn） 與 Web 應用程式（如 FastAPI、Starlette、Django） 之間的標準介面。
