CSS 版面是決定家具要擺哪裡的「室內設計圖」，RWD 是讓這個房間能像變形金剛一樣自動適應手機與電腦螢幕
CSS 版面的目的，就是決定網頁元素要擺在哪裡、怎麼擺
RWD：同一個網頁，會根據使用者螢幕的大小自動改變排列方式
Mobile-first（行動優先）
1.從手機版開始設計（預設樣式）：
先為最小的螢幕設計最核心、最簡潔的介面。因為手機畫面小、網路可能較慢，這樣能逼自己只保留最重要的功能與乾淨的程式碼。
2.螢幕變大時再逐步升級（由小變大）：
使用 CSS 的 min-width（最小寬度）條件，當使用者用平板或電腦打開時，才漸進式地加上更多的欄位、側邊欄或複雜的視覺效果。
